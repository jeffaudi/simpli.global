<p>Esta página explica el razonamiento detrás del alfabeto Simpli: qué letras usamos, la regla <strong>V</strong> y <strong>W</strong> (sonidos equivalentes) y por qué mantenemos <strong>i</strong> y <strong>y</strong>.</p>

  <h2>El alfabeto completo</h2>
  <p>Simpli usa un conjunto de letras reducido y regular. Cada sonido se escribe con una letra; no hay letras mudas ni símbolos extra.</p>
  <p><strong>Vocales:</strong> a, e, i, o, u (largas: aa, ee, ii, oo, uu — letra doblada).</p>
  <p><strong>Consonantes:</strong> p, b, t, d, k, g, m, n, f, s, l, r, h, <strong>v</strong>, w, y. <strong>No hay letra c</strong> (eliminada). Se usa <strong>k</strong> para /k/. El sonido /tʃ/ se escribe <strong>tj</strong>; /dʒ/ se escribe <strong>dj</strong> (simétrico con tj). <strong>G</strong> representa siempre el sonido /g/ duro. El sonido [v]/[w] se escribe <strong>w</strong> cuando el inglés usa <strong>w</strong>, si no <strong>v</strong>.</p>

  <h2>V y W (sonidos equivalentes)</h2>
  <p>En Simpli los sonidos [v] y [w] del inglés son <strong>equivalentes</strong>. Usa <strong>w</strong> cuando el inglés escribe el sonido con <strong>w</strong> (al inicio o dentro de la palabra). Usa <strong>v</strong> cuando el inglés usa <strong>v</strong>. Se pueden pronunciar de una u otra forma.</p>
  <p>Ejemplos:</p>
  <ul>
    <li><em>water</em> → <strong>woter</strong></li>
    <li><em>whatever</em> → <strong>watever</strong></li>
    <li><em>woman</em> → <strong>wuman</strong></li>
    <li><em>wi</em>, <em>windo</em> — se conserva la <strong>w</strong> del inglés</li>
    <li><em>seven</em> → <strong>seven</strong></li>
    <li><em>have</em> → <strong>hav</strong></li>
    <li><em>give</em> → <strong>giv</strong></li>
    <li><em>live</em> → <strong>liv</strong></li>
    <li><em>move</em> → <strong>mov</strong></li>
    <li><em>river</em> → <strong>river</strong></li>
    <li><em>even</em> → <strong>even</strong></li>
  </ul>
  <p>Así: sigue la <strong>w</strong> o <strong>v</strong> del inglés cuando esa letra marca el sonido [w]/[v].</p>

  <h2>¿Por qué i y y?</h2>
  <p>Mantenemos <strong>i</strong> y <strong>y</strong> porque representan <strong>sonidos distintos</strong>:</p>
  <ul>
    <li><strong>i</strong> es una <strong>vocal</strong> (núcleo silábico): el sonido de <em>sit</em>, <em>see</em>, <em>it</em>, <em>eat</em> — corto o largo (escrito <em>ii</em>). Ejemplos: <em>mi</em>, <em>bi</em>, <em>tri</em>, <em>sii</em>, <em>faind</em>, <em>pipol</em>, <em>gud</em>, <em>iit</em>.</li>
    <li><strong>y</strong> es una <strong>consonante</strong> (el glide [j]): el sonido al inicio de <em>yes</em>, <em>you</em>, <em>year</em>. Ejemplos: <em>yu</em>, <em>yes</em>, <em>yesterde</em>, <em>yelo</em> (yellow). (El dígrafo <strong>dj</strong> se usa para /dʒ/, un sonido distinto.)</li>
  </ul>
  <p>A diferencia de v y w, no los fusionamos: son dos fonemas distintos (vocal vs consonante). Usar <strong>y</strong> para [j] mantiene la ortografía clara: <em>yu</em> (you) y <em>yes</em> se leen bien; <em>iu</em> o <em>ies</em> mezclarían la consonante con la vocal. Por eso conservamos <strong>i</strong> y <strong>y</strong>.</p>

  <h2>G y dj</h2>
  <p><strong>G</strong> representa siempre el sonido /g/ duro (como en <em>go</em>, <em>gud</em>, <em>giv</em>, <em>langwidj</em>). Nunca representa el /dʒ/. <strong>dj</strong> representa /dʒ/ (simétrico con <strong>tj</strong> para /tʃ/): <em>djob</em>, <em>djeneral</em>, <em>djaiant</em>, <em>meidjer</em>, <em>bridj</em>. Este contraste hace la pronunciación predecible.</p>

  <h2>Otras letras que no usamos</h2>
  <p>Simpli también elimina o sustituye otras letras del inglés para mantener un alfabeto pequeño y fonético:</p>
  <ul>
    <li><strong>th</strong> → d (<em>dis</em>, <em>dat</em>, <em>dey</em>)</li>
    <li><strong>c</strong> — no se usa en Simpli. Se usa <strong>k</strong> para /k/ (ej. <em>skul</em>, <em>akson</em>). El sonido /tʃ/ se escribe <strong>tj</strong>: <em>tjaild</em> (child), <em>tiitjer</em> (teacher), <em>tjeenj</em> (change), <em>tjiiz</em> (cheese).</li>
    <li><strong>ph</strong> → f (<em>fon</em>)</li>
    <li><strong>sh</strong> → s; <strong>z</strong> → s cuando haga falta</li>
  </ul>

  <h2>Por qué falla la regla automática c → k</h2>
  <p>Porque la <strong>c</strong> en inglés puede corresponder a sonidos distintos:</p>
  <ul>
    <li>cat → /k/ → <em>kat</em></li>
    <li>city → /s/ → <em>siti</em></li>
    <li>ocean → /ʃ/ o /ʃən/ según contexto, no <em>okean</em></li>
    <li>special → no <em>spekial</em></li>
    <li>electric → la c final es /k/, pero no toda c en inglés lo es</li>
  </ul>
  <p>Así que la regla real no es «sustituir c por k», sino:</p>
  <ul>
    <li>/k/ → k</li>
    <li>/s/ → s</li>
    <li>/tʃ/ → tj</li>
    <li>/dʒ/ → dj</li>
    <li>y a veces otros resultados según la pronunciación real</li>
  </ul>

  <h2>El mismo problema con otras letras</h2>
  <p>También aplica a:</p>
  <ul>
    <li><strong>g:</strong> go /g/ vs general /dʒ/</li>
    <li><strong>x:</strong> box /ks/, xylophone /z/, exact /gz/</li>
    <li><strong>th:</strong> think /θ/, this /ð/</li>
    <li>las <strong>vocales</strong> en todas partes</li>
  </ul>
  <p>Por tanto, un corpus Simpli serio no puede construirse solo con sustituciones ortográficas. Hay que partir de la <strong>pronunciación</strong> y luego aplicar el inventario fonémico Simpli (ver <a href="..">Ortografía</a> → «Cómo definir la ortografía de una palabra»).</p>
