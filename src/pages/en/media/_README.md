# Media routes (`/en/media`)

**Note:** `_README.md` avoids Astro emitting `/en/media/README` as a page.

- **`index.astro`** — Lists printable leaflet and static share assets (`/media/…`).

French and Spanish folders mirror these files with the same structure and translated UI strings.
