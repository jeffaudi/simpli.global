# Components (`src/components`)

Reusable Astro chunks for the Simpli site.

| File | Role |
|------|------|
| `Header.astro` / `Footer.astro` | Site chrome; grouped header nav; compact footer (quick links + CC BY 4.0) |
| `NextStepsContent.astro` | Next steps grid (status badges, env-based Discord/forum, links to lessons/tools/media) |
| `DiscussionCommunitySection.astro` | Discussion page CTA (Discord, forum, contact) |
| `i18n/*` | Locale switcher and HTML `lang` helpers |
