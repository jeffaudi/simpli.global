# Brand (`public/brand`)

Logo files for the site, taken from the Simpli illustrations. Colors live in `src/styles/base.css`.

| File | Use |
|------|-----|
| `wordmark.png` | Header and printable leaflet. Transparent background. |
| `mark.png` | Overlapping speech bubbles. Shown above the wordmark on the home page. |
| `apple-touch.png` | Home-screen icon. |

| Role | Hex |
|------|-----|
| Wordmark purple | `#410760` |
| Orange i-dot | `#ff8004` |
| Cream field | `#fcf2f0` |
| Lavender corner | `#e4c6fc` |
| Coral corner | `#fe907f` |
| Yellow corner | `#fdd073` |
| Pink corner | `#e89ae5` |

The favicon is `public/favicon.svg`. The share card is `public/media/share-simpli.svg` (and `share-simpli.jpg` for link previews).
