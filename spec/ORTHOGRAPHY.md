# Simpli Orthography

## Alphabet

- **Vowels:** a, e, i, o, u (long: aa, ee, ii, oo, uu — doubled letter).
- **Consonants:** p, b, t, d, k, g, m, n, f, s, l, r, h, w, y.

No *th*, *v*, *z*, *sh*, *ch*, *j*; mapped (e.g. th → d).

## Rules

1. One sound = one spelling; no silent letters.
2. Long vowels = doubled letter (e.g. *it* vs *iit* for “eat”).
3. Syllable structure: (C)V(C). Stress on second-to-last syllable.
4. Common endings: -tion → -son, -sion → -son, -ture → -tur.
