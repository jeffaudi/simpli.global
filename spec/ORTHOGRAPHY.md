# Simpli Orthography

## Alphabet

- **Vowels:** a, e, i, o, u (long: aa, ee, ii, oo, uu — doubled letter).
- **Consonants:** p, b, t, d, k, g, m, n, f, s, l, r, h, w, y.

No *th*, *v*, *z*, *sh*, *ch*, *j*; mapped to nearest letter (see below).

## Letter mappings

- **th** → d (*dis*, *dat*, *dey*)
- **v** → w — we never write *v* in Simpli; always *w*: *sewen* (seven), *wata* (water), *wuman* (woman), *haw* (have), *giw* (give), *liw* (live), *mow* (move), *riwer* (river), *ewen* (even)
- **ch** → c (*ticer*, *caild*)
- **ph** → f (*fon*)
- **sh** → s; **j** → y or d; **z** → s when needed

## Rules

1. **One sound = one spelling;** no silent letters (*lait*, *windo*, *dor*, *bred*, *faind*, *plei*).
2. **Long vowels = doubled letter:** *it* vs *iit* (eat), *rod* vs *rood* (road), *rum* vs *ruum* (room). The aim is to **differentiate homonyms**; in general **context is enough** to understand. Diphthongs: /aɪ/ → **ai** (*bai*, *caild*), /eɪ/ → **ei** (*plei*).
3. **Syllable structure:** (C)V(C). Stress on second-to-last syllable (*komputer*, *yesterde*, *tumoro*).
4. **Common endings:** -tion/-sion → -son, -ture → -tur, -ous → -us.

See the [Spelling](/en/spelling) and [Alphabet rationale](/en/spelling/alphabet-rationale) pages on the website for full detail (including why we use W and not V).
