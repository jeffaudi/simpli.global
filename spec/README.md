# Simpli language specification

Reference documents for the Simpli language (orthography, grammar, vocabulary). The live site at [simpli.global](https://simpli.global) presents the same content in a multilingual, navigable form.

- [ORTHOGRAPHY.md](ORTHOGRAPHY.md) — Alphabet and spelling rules
- [PRONUNCIATION.md](PRONUNCIATION.md) — Canonical IPA, accepted variants, and sounds that need a listener check
- [PRONUNCIATION-AUDIT.md](PRONUNCIATION-AUDIT.md) — What the current pages and word list actually do, and spelling changes that are not adopted yet
- [GRAMMAR.md](GRAMMAR.md) — Core grammar rules (including numbers, dates, and time)
- [VOCABULARY.md](VOCABULARY.md) — Vocabulary strategy and essential words
